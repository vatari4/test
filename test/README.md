# EmployeeApp

Простое консольное приложение на C# (.NET 8) для управления сотрудниками.
Проект демонстрирует безопасную работу с базой данных MS SQL Server через ADO.NET с использованием Windows-аутентификации.

---


### 1. Установка зависимостей Для работы с MS SQL Server убедитесь, что установлены следующие NuGet-пакеты:

```bash
dotnet add package Microsoft.Data.SqlClient
```

### 2. Создание базы данных
```bash
sqlcmd -S localhost -E -Q "CREATE DATABASE EmployeeDB"
```

### 3. Запуск приложения

```bash
dotnet run
```

---


При запуске приложение:
- Подключается к MS SQL Server через Windows-аутентификацию,
- создаёт таблицу Employees, если её нет,
- откроет консольное меню для управления сотрудниками.

---

## Функциональность

- Добавление нового сотрудника  
- Просмотр всех сотрудников  
- Обновление данных сотрудника  
- Удаление сотрудника  
- Подсчёт количества сотрудников с зарплатой выше средней
